# react-wordgard

React, Vue and Svelte views for [Wordgard](https://www.wordgard.net): the Wordgard document drawn
with your app's framework and contexts, and any decoration that takes a shape, a wrapper or a widget
can be a component. Wordgard keeps doing the rest (input, selection, composition), and the API stays
Wordgard's.

| Package                                              | For                                               |
| ---------------------------------------------------- | ------------------------------------------------- |
| [`@stesura/react-wordgard`](packages/react#readme)   | React 18 and 19                                   |
| [`@stesura/vue-wordgard`](packages/vue#readme)       | Vue 3.5                                           |
| [`@stesura/svelte-wordgard`](packages/svelte#readme) | Svelte 5, SvelteKit included                      |
| [`@stesura/wordgard-view`](packages/core#readme)     | Their shared core, which they bring: not for apps |

The four are released together, at one version. How they work:
[docs/how-it-works.md](docs/how-it-works.md). Developing them: [CONTRIBUTING.md](CONTRIBUTING.md).
